# PowerBi-Rework-AI
Data analysis and AI project combining Python, Power BI, K-Means clustering and Random Forest to analyze and predict cable rework.

## Overview

This project focuses on analyzing cable rework data and identifying the main factors associated with rework.

A **Power BI dashboard** was developed to visualize key insights, while **Machine Learning techniques** were used for clustering and rework prediction.

## Objectives

* Analyze and clean rework data
* Identify patterns and groups using **K-Means clustering**
* Predict rework using a **Random Forest classifier**
* Develop an interactive **Power BI dashboard**

## Technologies

* Python
* K-Means
* Random Forest
* Power BI

## Workflow

```text
Raw Data
   ↓
Data Cleaning
   ↓
Data Analysis
   ↓
K-Means Clustering
   ↓
Random Forest Prediction
   ↓
Power BI Dashboard
```

>  Original company datasets are not included due to confidentiality.
